# Бот для креаторов TITAN VPS

Отдельный бот рядом с основным (@TitanVPS_bot). В основной бот и в панель Remnawave он ничего не пишет: базу `vpn_bot.db` открывает только на чтение, к Remnawave (если подключить) отправляет только GET-запросы.

**Админ (вы):** создаёт креатора, задаёт ставку за пользователя, закрепляет за ним кампанию из «Продвижения», видит статистику, подтверждает или отклоняет выводы.

**Креатор:** видит свою ссылку, сколько человек пришло, сколько подключилось, сколько заработано и выплачено, заказывает вывод от 1 000 ₽.

## Как считается оплата

1. Для креатора создаётся кампания в разделе «Продвижение» админки основного бота. Ссылка этой кампании — ссылка креатора.
2. Основной бот сам записывает пришедших по ней пользователей (`users.invited_by` = ID кампании).
3. Раз в 5 минут бот креаторов читает базу: новые пользователи кампании и их подключение (`online_at` и трафик не меньше 5 МБ).
4. За каждого подключившегося креатору начисляется его ставка и приходит уведомление.

Не оплачиваются:
- пользователи, пришедшие до закрепления кампании (если при создании выбрано «Только новых»);
- не подключившиеся за 3 дня (срок пробного периода, настраивается в `QUALIFY_DAYS`);
- повторное устройство с уже засчитанным HWID (только если заполнены `REMNA_URL` и `REMNA_TOKEN`).

Ставка фиксируется в момент подключения: её изменение не меняет прошлые начисления. Отключённому креатору новые пользователи не засчитываются.

## Установка (на сервере с основным ботом)

```bash
# upload creator_bot.zip to /root, then:
unzip /root/creator_bot.zip -d /opt && cd /opt/creator_bot
python3 -m venv venv
./venv/bin/pip install -r requirements.txt
cp .env.example .env
nano .env
```

В `.env` обязательно заполнить:
- `BOT_TOKEN` — новый бот из @BotFather;
- `ADMIN_IDS` — ваш Telegram ID.

Проверка на реальной базе до запуска (только чтение):

```bash
./venv/bin/python check_campaign.py 85537893175 7
```

Запуск как службы:

```bash
cp creator-bot.service /etc/systemd/system/
systemctl daemon-reload
systemctl enable --now creator-bot
journalctl -u creator-bot -f
```

## Порядок работы

1. В админке основного бота: «Продвижение» → «Новая кампания» (например, «Креатор nick», источник TikTok, расход 0).
2. В боте креаторов: «➕ Новый креатор» → имя → ставка → ссылка кампании (или её ID).
3. Если по кампании уже были пользователи, бот спросит, засчитывать их или только новых.
4. Отправьте креатору ссылку-приглашение `...?start=join_...`, по ней он попадает в свой кабинет.
5. Заявки на вывод приходят вам с кнопками «Выплачено» и «Отклонить». При отклонении сумма возвращается на баланс креатора.

Перед выплатой можно открыть в карточке креатора «📋 Последние пользователи» и проверить, кто засчитан.
